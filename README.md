# Data Cleaning

Data cleaning is one of the most important steps in data analysis.

## Numerical Columns Cleaning

Numerical missing values were filled using median values.

```python
for column in df_num.columns:
    df_num[column] = df_num[column].fillna(df_num[column].median())
```

### Why Median?

Median reduces the effect of outliers.

---

## Categorical Columns Cleaning

Categorical missing values were filled using mode values.

```python
for column in df_cat:
    mode = (df_cat[column].mode().values[0])
    df_cat[column] = df_cat[column].fillna(mode)
```

### Why Mode?

Mode represents the most frequent category.

---

## Combining Numerical and Categorical Data

```python
df = pd.concat([df_num, df_cat], axis=1)
```

# Feature Engineering

Feature engineering was performed to create new useful columns.

---

## Discounted Amount

A new column named discounted_amount was created.

```python
df["discounted_amount"] = df["original_price"] - df["discounted_price"]
```

### Purpose

To identify how much amount was reduced from original price.

---

## Estimated Revenue

A new column named estimated_revenue was created.

```python
df["estimated_revenue"] = df["discounted_price"] * df["purchased_last_month"]
```

### Purpose

To estimate monthly revenue generated by products.

---

## Percentage Band

Discount percentages were grouped into categories.

```python
df["percentage_band"] = pd.cut(

    bins=[0,10,30,70,99],
    labels=["less discount","medium discount","High","very high"]

```

### Categories

* Less Discount
* Medium Discount
* High Discount
* Very High Discount
